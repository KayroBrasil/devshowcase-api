CRIAR RAMIFICAÇÃO DA SUA TAREFA:
git branch nome-da-tarefa

TROCAR PARA SUA RAMIFICAÇÃO:
git checkout nome-da-tarefa

DESENVOLVER AS PÁGINAS SOLICITADAS;

VERIFICAR QUAIS ARQUIVOS FORAM MODIFICADOS:
git status

ADICIONAR OS ARQUIVOS ALTERADOS:
git add nome-do-arquivo nome-da-pasta

SALVAR AS ALTERAÇÕES LOCALMENTE:
git commit -m "Nome da tarefa finalizada."

ENVIAR PARA O REPOSITÓRIO REMOTO:
git push -u origin nome-da-tarefa

BAIXAR TODAS AS ALTERAÇÕES FEITAS:
git pull origin main
